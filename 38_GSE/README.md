## Intent、Spec、Impl

三个空间
- Intent Space，需求的提出者也不 100% 确定他想要什么，比如“做一个国民级的应用”。老板或甲方的需求，无计算机背景
- Spec Space，从 Intent 到 Spec，已经曲解了很多。技术方案？页面排布？
- Impl Space，计算机程序只接受 100% 无歧义的指令。

“正确”发生在那一层？只在 Spec 到 Impl，只是能跑且规格正确，并不一定满足意图。测试可以证明前者，无法替人决定后者。
