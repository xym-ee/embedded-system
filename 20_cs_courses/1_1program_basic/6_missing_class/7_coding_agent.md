### LLM 基本原理

coding agent 大致分两部分，LLM 和 包裹(wrapping) LLM 的 外部软件 (agent harness)

LLM 对补全字符串的概率分布进行建模。

实际应用中，模型都有上下文窗口的限制。输入字符串和输出字符串的长度都存在上限。


### 聊天功能如何实现

### coding agent

对 LLM 的输出做一些解析处理。

LLM 可以输出文本，也可让起输出 调用工具 这种指令。特调一个模型，输出在计算机上执行操作的请求指令。

设计一套 harness ，接收 LLM 输出，解析 LLM 的想法，执行具体地动作，拿到执行结果，再返回给 LLM，这就是一轮对话。
