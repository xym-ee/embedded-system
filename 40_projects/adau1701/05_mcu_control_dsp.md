# MCU 控制 ADAU1701

## 分工

MCU 和 ADAU1701 的关系可以先理解成控制面和音频数据面的分工：

```text
MCU
  -> 下载程序
  -> 写参数
  -> 切换模式
  -> 处理人机交互和通信

ADAU1701
  -> 实时处理音频采样
  -> 保持低延迟音频链路
```

MCU 不适合在普通控制任务里逐点处理音频采样。它更适合管理 DSP 的运行状态。

## 常见控制内容

- 音量。
- 静音。
- 输入源选择。
- EQ 参数。
- 音效开关。
- 不同场景的参数表切换。

## 工程实现关注点

- I2C / SPI 写寄存器和参数 RAM 的时序。
- 参数更新是否会产生爆音。
- 多字节参数的端序和格式。
- 固件中如何管理 SigmaStudio 导出的数据。
- 上电初始化失败时如何重试或降级。

这部分可以结合 ESP32、STM32 或其他主控展开，但笔记仍然优先放在 ADAU1701 目录里。
