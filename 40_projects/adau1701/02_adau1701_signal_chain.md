# ADAU1701 信号链路

## 基本链路

ADAU1701 集成了音频 ADC、DAC 和 SigmaDSP 内核，适合做小型音频处理系统。

可以先按下面的链路理解：

```text
模拟输入
  -> ADC
  -> DSP 内部处理
  -> DAC
  -> 模拟输出
```

如果系统中还有其他数字音频芯片，也可能通过数字音频接口接入，但当前阶段先从模拟输入和模拟输出开始，最容易形成直观反馈。

## 需要关注的硬件问题

- 电源：模拟电源、数字电源和地的处理。
- 时钟：主时钟来源，以及采样率如何确定。
- 复位：上电时序和复位脚状态。
- 控制接口：I2C 或 SPI。
- 自启动：是否外接 EEPROM。
- 模拟链路：输入幅度、输出幅度、偏置、耦合电容和噪声。

## 调试时的观察点

- 输入有没有信号。
- ADC 之后的信号在 SigmaStudio 中是否能被正确路由。
- DSP 程序是否下载成功。
- DAC 是否有输出。
- 输出是否削波、过小、噪声过大或左右声道反了。

先把最短链路跑通：

```text
输入 -> 直通 -> 输出
```

直通链路稳定以后，再逐步加入音量、混音、EQ 和其他模块。
