# SigmaStudio 基本工作流

## SigmaStudio 解决什么问题

SigmaStudio 把音频处理链路图形化。对 ADAU1701 来说，它既是算法搭建工具，也是程序和参数生成工具。

嵌入式工程师可以先把它理解成：

- 用模块搭建 DSP 信号流图。
- 编译生成 ADAU1701 可运行的程序和参数。
- 通过下载器直接写入芯片调试。
- 导出 MCU 或 EEPROM 启动需要的数据。

## 最小实验

第一步不要做复杂效果，先做直通：

```text
Input
  -> Volume
  -> Output
```

这个实验要确认几件事：

- 硬件连接正确。
- SigmaStudio 能识别下载器。
- 程序可以下载到 ADAU1701。
- 调节模块参数时，输出声音能实时变化。

## 后续模块

可以逐步加入：

- 音量控制。
- 静音开关。
- 左右声道混合。
- EQ。
- 简单滤波。
- 动态处理。

当前阶段只需要知道这些模块如何被调用、连接和调参，不需要马上理解每个模块的完整算法细节。
