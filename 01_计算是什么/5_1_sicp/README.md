## 黑盒抽象


计算机科学是介绍计算机使用的？

举个例子，数学中的平方根的定义

> $ \sqrt{x} $ is the $ y $ such that $ y^2 = x $ and $ y \ge 0 $

这是一个很清晰的定义，但只定义了平方根是什么，并没有说如何去求。

如何去求？

一个算法，牛顿迭代法。


问题，给一个正数 $ a $，求 $ x = \sqrt{a} $。

改写成一个求零点问题 $ f(x) = x^2 - a = 0 $，找到这个方程的根，即为 $ \sqrt{a} $。


步骤，

猜测一个 $ x_0 $，做切线 $ l_0 $，找 $ l_0 $ 和 $ x $ 轴的交点 $ x_1 $

在 $ x_1 $ 做切线 $ l_1 $，找 $ l_1 $ 和 $ x $ 轴的交点 $ x_2 $

···

直到满足要求。

根据上面的思路，可以推导出公式

$$
x_{n+1} = \frac{ x_n + a/x }{2}
$$

直观理解：当前猜测值为 $ x_n $，真值应该满足 $ x = a/x $，所以取平均。

牛顿法，二阶收敛。

一个算法：连续均值求平方根法。给一个猜测值 $ g $ 。不断求猜测值 guess 与 X/guess 的平均值

找一个 $ \sqrt{x} $ 的近似值

- 猜测一个 $ g $
- 求 $ g $ 与 $ x/g $ 的平均值来提升精度
- 直到精度满足要求


上面这个就是一个计算过程。

## 控制复杂度的方法：约定接口

如果想表达一个想法，想法，

比如将一个元素与另外两个元素之和相乘这个想法。这是一个线性组合的基本想法，在实数域讨论是很容易的，如 1+3 *2 = 8


```lisp
(*x (+ a1 a2))

; (*2 (+ 1 3)) -> 8
```

如果想将这个想法应用于向量，两个向量相加，然后来个倍数得到另一个向量。

再或者，a1 a2 都是多项式。

如 $$ ((x^3 + x - 1) + (x^2 - 2x + 8)) * 2 $$

对两个多项式求和然后来个倍数

甚至是，a1 a2 都是电信号，两个电信号相加送入一个放大器，

这种想法的基本点是，希望用一个通用的记号表示这些。

如果我们的语言可以很好的表述这类想法，就可以用这样的方式来表达 `(*x (+ a1 a2))`

可以做更进一步的抽象表达，使其适应各个不同类型的 a1 和 a2

但是呢，这个想法似乎也有一些问题，因为对两个数字相加和两个多项式进行加和运算所用的基本操作在机器内部显然是不同的。

对不同类型的元素相加需要用不同的方法，为了构建这样一个系统，如何使用这些知识呢？如果突然过两天又来了一个新的类型对象，如何吧这个新类型引入系统又不把已有系统搞的一团糟。

这就是第二个话题，控制复杂度的方法。

我们实现的方法是按照约定来实现相应的接口。

conventional interfaces

并以此将各部分组合起来，就如同物理上的接口，标准一致就可以插起来。

## 元语言抽象

控制复杂度的第三个技术，定义新的语言。

当受不了设计的复杂度时，可以通过定义一门新的语言来控制系统复杂度。新语言的设计意图是为了强调系统的某个方面，他一方面隐藏了部分细节，另一方面强调了一些其他细节。这部分是这门课最神奇的部分，尝试构建新的计算机语言

一些前置工作已经内建在 lisp 中了，后面会尝试用 lisp 去解释 lisp，类似于一个自循环的过程，此实现与一个神奇的符号有关，

解释 lisp 的步骤，应用和求值，两个步骤轮转，不断互相交替进行，

此外还有一些神奇的东西，如魔法符号 $$ \lambda $$，Y 运算符，某种意义上，在过程式语言中用于表达无限，

这部分课程被称作 源语言抽象，主要讨论如何构建一门新语言，从了解解释的过程开始，然后讨论应用-求值循环和构建 lisp，。这个过程中会发现这种方法具有相当的普遍性，可以用同样的技术去构建一门完全不同的语言：一种逻辑编程语言，无关具有输入和输出的过程，仅关注元素之间关系的语言

最终，讨论如何将这些东西实实在在的实现在简单的机器上，
  
这三个主题就是这个课程的提纲：黑盒抽象，约定接口，元语言抽象
