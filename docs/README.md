# Codex 文档入口

这个目录放给 Codex 和后续整理工具看的说明，不作为普通读者的主入口。

建议先读：

- `codex-guide.md`：仓库定位、根目录约定、内容归类规则。
- `structure-adjustment-record.md`：目录结构调整记录，尤其是 35、38、39 这些接触型方向的降级处理。
- `planning-notes.md`：早期整理计划和思路草稿，保留作历史参考。
- `tools/gen_summary.py`：生成 `SUMMARY.md` 的脚本。

根目录只保留必要入口文件：`AGENTS.md`、`README.md`、`SUMMARY.md`。
