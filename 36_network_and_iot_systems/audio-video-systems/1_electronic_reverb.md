# 电子混响效果实现记录

## 这个问题是什么

电子混响要解决的问题，是让一段原本比较干的声音听起来像是在某个空间里发出来的。

真实空间里的声音不是只沿着一条路径到达人耳。它会包含：

- 直达声：声源直接传到听者的位置。
- 早期反射：声音碰到墙面、地面、桌面后较快返回。
- 混响尾音：大量反射不断叠加、衰减，最后形成一段逐渐消失的尾巴。

混响 是 当前声音 + 很多延迟后的、变弱的、被滤波的声音叠加

最直接的方法：卷积混响，计算量大。

常用的实时方法：延迟线+反馈。

用延迟、衰减、反馈和混合去构造一种类似空间反射的听感。

## 核心模型

最小的电子混响可以先理解成一个带反馈的延迟线。

原始输入是 `x[n]`，输出是 `y[n]`。先从过去某个时刻取出一个延迟采样，再按一定比例反馈回缓冲区：

```text
delay_samples = sample_rate * delay_ms / 1000

delayed = buffer[read_index]
buffer[write_index] = x[n] + feedback * delayed
y[n] = dry * x[n] + wet * delayed
```

其中：

- `delay_ms` 决定反射多久以后回来。
- `feedback` 决定尾音能持续多久。
- `dry` 是原始声音比例。
- `wet` 是混响声音比例。

如果只有一条延迟线，效果更像回声。想让它更像自然混响，通常需要多条不同长度的延迟线，再加一些扩散和滤波处理，让反射变得更密集、不那么机械。

## 实现链路

这次实现可以先按下面这条链路理解：

```text
输入采样
  -> 保存历史采样到环形缓冲区
  -> 从缓冲区读取延迟采样
  -> 延迟采样按反馈系数写回
  -> 原声和效果声混合
  -> 输出采样
```

这里最关键的数据结构是环形缓冲区。音频是连续流，不能每来一个采样就整体移动数组，所以需要用读写下标在固定长度的缓冲区中循环移动。

## 关键参数

- 采样率：决定 `delay_ms` 最终对应多少个采样点。
- 延迟时间：太短会更像梳状滤波，太长会听出明显回声。
- 反馈系数：越大尾音越长，但超过安全范围会导致声音失控。
- 干湿比：决定原声和混响声的混合程度。
- 缓冲区长度：至少要覆盖最大延迟时间。

## 容易出错的地方

- 延迟时间要换算成采样点，而不是直接拿毫秒当数组长度。
- 反馈系数不能太大，否则能量会不断积累，最后削波或啸叫。
- 分块处理音频时，环形缓冲区状态要跨块保留，不能每个 block 都重新初始化。
- 如果输出格式是 `int16`，混合后需要处理幅值范围，避免直接溢出。
- 双声道不能简单只处理一边，后面可以考虑左右声道使用略微不同的延迟参数，增强空间感。

## 后续可以继续实验

- 多个 comb filter 并联，让反射密度更高。
- 加入 all-pass filter，让声音扩散得更自然。
- 在反馈路径上加低通滤波，模拟高频在空间中更快衰减。
- 加入 pre-delay，让直达声和混响声之间有一点间隔。
- 做 dry / wet、room size、decay 等参数控制，方便实时调效果。

## 相关问题

- 音频效果器本质上是在时间序列上做变换。
- 延迟、反馈和滤波是很多声音效果的基础。
- 电子混响虽然听起来是一个“效果”，但底层其实是缓冲区、采样率、状态保存和实时处理这些工程问题。
