# 音视频系统

这里放网络视频流、音频处理和多媒体应用系统相关的工程实践。

这部分内容不以传输协议的底层实现为主，而是关注一个音视频系统如何被搭起来、跑起来、调试起来：

- 网络视频流：RTSP、RTMP、HLS、WebRTC、SRT 等应用层流媒体方案。
- 音频处理：采样率、重采样、编码、降噪、回声消除、混音等常见处理链路。
- 多媒体工具链：FFmpeg、GStreamer、OBS、VLC、mediamtx、nginx-rtmp 等。
- Linux 音视频接口：V4L2、ALSA、PulseAudio、PipeWire 等用户态接口。
- 嵌入式场景：摄像头采集、硬件编解码、边缘设备推流、局域网拉流。
